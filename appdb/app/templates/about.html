About

HyperHLE is a community fork of the touchHLE iPhone OS emulator, maintained at j92580498-max/touchHLE. This site is its compatibility database — anyone can submit a report for an app they've tested in HyperHLE: app name, version, OS / device, GPU, rating, remarks, and a screenshot.

Submitting a report

The fastest way to submit a report is to upload your HyperHLE log file on the submit page — the site will pull the app name, version, bundle identifier, GPU, OS and emulator version straight out of the log so you only need to add a rating, remarks and (optionally) a screenshot.

Inspiration

This site is modelled on the original appdb.touchhle.org by upstream touchHLE. HyperHLE is an independent community fork; this database is not affiliated with upstream.

Moderation

Submitting a report requires signing in with GitHub. Reports go into a moderation queue reviewed by the site admins before they appear publicly. The current admins are:

  • @TimofeyLednev
  • @j92580498-max
  • @makaherpasswordlostmedia

We only request the GitHub read:user scope — public profile info (id, login, avatar). No email access, no repo access.

House rules

  • Only test apps you legally own.
  • No links to pirated content. “Abandonware” is still piracy.
  • Be precise — include the HyperHLE version, your OS, your GPU.
